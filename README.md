# MirthPrism

MirthPrism is a healthcare data processing engine that leverages broker-gateway model to enable real-time message routing and processing.

MirthPrism is built to be simple and practical, focusing on doing one thing well.

**Why MirthPrism?**

- MirthPrism is a healthcare data
- processing engine that leverages broker-gateway
- model to enable real-time message

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/MirthPrism.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

To configure MirthPrism, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
